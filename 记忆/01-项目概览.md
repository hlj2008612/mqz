# 项目概览

## 定位

个人照片墙网站，作者「美琴子」。线上地址 <https://zmq-hlj.ccwu.cc/>，源码仓库 <https://github.com/hlj2008612/mqz>。

## 技术栈

| 项 | 版本/说明 |
|---|---|
| 框架 | Vue（实际安装 **3.5.43**，`<script setup>` + Options API 混用） |
| 路由 | vue-router（实际 **4.6.4**），**hash 模式**（`createWebHashHistory`） |
| 构建 | Vite（实际 **8.3.0**）+ @vitejs/plugin-vue（实际 **6.0.9**） |
| 样式 | 原生 CSS，无 UI 框架、无 Tailwind |
| 动画 | 纯 CSS `@keyframes` + 手写 JS（**已移除 GSAP**） |
| 依赖 | 运行时仅 `vue` + `vue-router`，无第三方 UI 库 |

> ⚠️ **版本号陷阱（重要）**：`package.json` 声明的是 `vue ^3.4.0` / `vue-router ^4.3.0` /
> `vite ^5.0.0` / `@vitejs/plugin-vue ^5.0.0`，但 `package-lock.json` 与实际安装的是
> vue 3.5.43 / vue-router 4.6.4 / vite 8.3.0 / plugin-vue 6.0.9。
> **两边不一致，且 lock 里还残留 `gsap ^3.15.0`。**
> 详见 [03-构建与部署.md](03-构建与部署.md) 开头的「不要跑 npm install」。

```
src/
  App.vue                 根组件，转场调度中心
  main.js                 入口
  router/index.js         路由与登录守卫
  assets/main.css         全局样式 + ptr 转场全部 CSS
  components/
    NavBar.vue            顶部玻璃导航栏（含手机端断点）
    PtrTransition.vue     ptr 擦除转场覆盖层（525 行）
  core/                   照片墙渲染引擎
    config.js             世界尺寸常量、图片池校验
    state.js              全局可变状态
    renderer.js           卡片创建/定位/回收（渲染核心）
    inertia.js            惯性滚动与渲染循环
    input.js              指针/滚轮/键盘输入
    main.js               初始化与销毁
    imageManifest.js      图片清单（脚本生成，勿手改）
    utils.js              mod()
  views/
    Login.vue / PhotoWall.vue / Cinema.vue / Pictorial.vue / Home.vue
docs/                     实测规格文档（8 份：pictorial / cinema / mobile / mobile-nav-options /
                          hover-card / nav-scroll-and-popover / new-photos，及 review 报告）
scripts/                  图片优化管线（Node + Python/Pillow）
assets-src/images/zmq/    23 张原图（100.87 MB，不进 public）
assets-src/images/zmq-new/ 新到照片的暂存目录（未编号，复制成 <id>.jpg 后才进管线）
public/images/thumbnails/ 23 张缩略图（652 KB）
public/images/full/       23 张 1600px 大图（3.07 MB，悬停时按需加载）
```
